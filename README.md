# daily-habit

個人每日待辦與習慣管理工具。純前端網頁（HTML、CSS、JavaScript），不需要安裝、不需要帳號，資料只保存在你自己的瀏覽器。

## 功能

- **今日**：今天日期、已逾期與今天到期的未完成待辦、今天要完成的習慣與打卡。
- **所有待辦**：新增、編輯、刪除（會先確認）、標記完成／取消完成；可篩選「全部／未完成／已完成」。
  欄位：名稱（必填）、備註、截止日期（可不填）、優先程度（高／中／低）。
- **習慣**：新增每日習慣、改名、封存與還原；為今天打卡或取消打卡；每個習慣顯示最近七天紀錄與連續天數。
  - 同一個習慣同一天只會有一筆打卡。
  - 建立習慣之前的日期不算漏打卡。
  - 封存的習慣保留紀錄，但不列入「今日」應完成的習慣。
- **設定與備份**：匯出 JSON 備份、從備份完整還原、載入範例資料、清除所有資料。

## 操作說明

1. 第一次開啟會看到「歡迎使用」畫面，可以直接「新增第一筆待辦」、「新增第一個習慣」，或按「載入範例資料」先試用（範例名稱前會標示「（範例）」，不會自動加入）。
2. 手機上，畫面下方有四個分頁：今日、所有待辦、習慣、設定與備份；電腦上分頁在畫面上方。
3. 待辦前面的方框可勾選完成，再按一次即取消。「編輯」修改內容，「刪除」會先跳出確認。
4. 習慣卡片上按「完成打卡」為今天打卡，按「取消打卡」撤銷。七天紀錄圖示：
   ✓ 已完成、✕ 未完成、○ 今天尚未打卡、– 尚未建立、‖ 已封存。
5. 過了午夜（依你裝置的當地時間），頁面會自動切換到新的一天；從背景切回頁面時也會重新檢查日期。
6. 所有按鈕與表單都可用鍵盤操作（Tab 移動、Enter／空白鍵執行、Esc 關閉對話框）。

## 資料保存與限制（請務必閱讀）

- 資料存在瀏覽器的 `localStorage`（key：`daily-habit:data`），**不會上傳到任何伺服器，也不會寫進 GitHub**。
- **不會跨裝置或跨瀏覽器同步**：手機與電腦、Chrome 與 Safari 的資料都是分開的。
- 以下情況可能讓資料消失：清除瀏覽器資料、使用無痕／私密瀏覽、更換瀏覽器或裝置、部分瀏覽器（例如 iPhone Safari）在網站長期未使用時清除資料。
- **請定期到「設定與備份」→「下載備份檔」**，檔名例如 `daily-habit-backup-2026-10-20.json`，請存放在雲端硬碟等安全的地方。
- 還原備份會「完整取代」目前所有資料。還原前會先檢查檔案（資料版本、欄位、日期、識別碼）並顯示筆數；檢查不通過的檔案不會覆蓋任何資料。還原前可勾選「先下載目前資料的備份」。
- 如果瀏覽器中的資料損壞，網頁會顯示「無法讀取已儲存的資料」畫面，**不會自動清空**；你可以下載原始內容、從備份還原，或改用空白資料開始（原始內容會另外保留）。
- 如果瀏覽器空間已滿或禁止儲存，畫面會顯示錯誤，該次變更不會套用。
- 備份檔含有你的個人資料，請不要提交到 GitHub（`.gitignore` 已排除 `daily-habit-backup-*.json`）。

## 在自己電腦上預覽

網頁使用 JavaScript 模組，**不能直接雙擊 `index.html` 開啟**（瀏覽器會阻擋），請用本機伺服器：

```bash
# 在專案資料夾中執行（需要 Python 3，macOS 與多數 Linux 已內建）
python3 -m http.server 8000
```

然後在瀏覽器開啟 <http://localhost:8000/>。Windows 若指令是 `python`，請改用 `python -m http.server 8000`。

## 執行測試

需要 Node.js 18 以上（建議 20 或 22），不需安裝任何套件：

```bash
npm test
# 等同於 node --test
```

測試涵蓋日期判斷（含 Asia/Taipei 凌晨與跨午夜、日光節約時間）、待辦篩選、打卡去重、備份驗證與 localStorage 讀寫。

## 發布到 GitHub Pages（從 main 分支根目錄）

1. 確認要發布的內容已合併到 `main` 分支，且 `index.html` 與 `.nojekyll` 位於儲存庫根目錄。
2. 到 GitHub 儲存庫頁面，點選 **Settings**（設定）。
3. 左側選單點 **Pages**。
4. 在 **Build and deployment** 的 **Source** 選擇 **Deploy from a branch**。
5. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**。
6. 等待約 1～2 分鐘，頁面上方會顯示網址，通常是 `https://<你的帳號>.github.io/daily-habit/`。
7. 之後每次推送到 `main`，網站會自動更新（可能需要重新整理或清除快取）。

注意：

- 同一個網址（例如 `https://<帳號>.github.io/daily-habit/`）才會看到同一份資料；換網址、換網域都等於換一份新的瀏覽器儲存空間。
- 同一個 `github.io` 網域下的其他專案頁面共用同一個 localStorage 空間，本工具只使用 `daily-habit:` 開頭的 key，不會動到其他資料。

## 專案結構

```
index.html          主頁面
.nojekyll           告訴 GitHub Pages 不要用 Jekyll 處理
css/style.css       樣式
js/app.js           畫面與操作
js/dates.js         日期工具（當地日期鍵 YYYY-MM-DD）
js/todos.js         待辦邏輯（驗證、篩選、排序）
js/habits.js        習慣與打卡邏輯（去重、七天紀錄、連續天數）
js/stats.js         統計
js/schema.js        資料格式、驗證、版本遷移
js/backup.js        備份匯出與驗證
js/storage.js       localStorage 讀寫與錯誤處理
js/sample.js        範例資料
js/ids.js           識別碼
js/dom.js           安全建立畫面元素的小工具
tests/              Node.js 內建測試
scripts/browser-check.cjs  選用的瀏覽器自動檢查（需要 Playwright）
```
